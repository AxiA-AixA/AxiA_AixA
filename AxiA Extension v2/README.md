# AxiA Extension v2 — 프로젝트로 보내기

웹에서 본 이미지를 **우클릭 → AxiA로 보내기 → 프로젝트**로 보내요. AI가 태그를 붙이면 알림으로 태그를 보여 주고, **스펙 시트 열기** 버튼으로 그 프로젝트의 비주얼 스펙을 바로 열 수 있어요. 기존 `axia-prototype/extension`(v1)은 그대로 두었어요.

## 설치

1. AxiA v2를 켜요 (`AxiA Web v2/AxiA_v2_open.command`, Windows는 `.bat`). 사이트(3001)와 AI 분석기(8770)가 같이 켜져요.
2. Chrome 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `AxiA Extension v2` 폴더 선택.
4. v1 확장(“Axia로 보내기”)도 켜 두면 우클릭 메뉴가 두 개 보여요. 헷갈리면 v1은 꺼 두세요.

## 쓰는 법

| 하고 싶은 것 | 방법 |
|---|---|
| 이미지 한 장 | 이미지 위에서 우클릭 → **AxiA로 보내기** → 프로젝트 (★는 마지막에 쓴 곳) 또는 **보관함에만 넣기** |
| 한 페이지에서 여러 장 (Are.na 채널, Cosmos 클러스터, Behance·Dribbble 프로젝트, 포트폴리오 사이트) | 우클릭 → **이 페이지 이미지 여러 장 고르기…**, 또는 확장 아이콘 → 같은 버튼. 고르고 보낼 곳을 정해 **보내기** |
| 핀터레스트 보드 전체 | 보드를 연 채로 확장 아이콘 → **이 Pinterest 보드 전체 보내기** (최대 300장) |
| 태그 확인, 스펙 보기 | 보낸 뒤 알림에 태그가 떠요 → **스펙 시트 열기**. 확장 아이콘에서도 최근 보낸 이미지와 태그가 보여요 |

- 프로젝트 목록은 1분마다 새로 읽어요. 방금 만든 프로젝트가 메뉴에 없으면 확장 아이콘을 한 번 열면 바로 생겨요.
- 사이트(3001)가 꺼져 있고 분석기만 켜져 있으면 보관함에만 들어가요.
- 인스타그램·핀터레스트·Behance·Dribbble은 큰 이미지 주소로 바꿔서 보내요.
